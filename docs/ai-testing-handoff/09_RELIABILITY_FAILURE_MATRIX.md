# 09_RELIABILITY_FAILURE_MATRIX.md — Reliability & Failure Recovery Matrix

This matrix documents edge cases, failure conditions, fallback mechanisms, and recovery behavior across QAForge.

| Failure ID | Feature | Failure Condition | Current Behavior | Expected Behavior | Recovery Strategy | Test Verification |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `FAIL-001` | `FEATURE-001` | Corrupted / Malformed `package.json` in project root | Throws JSON parse error in `StackDetector.detect()` | Fallback to `vanilla` framework and default port `3000` | Log warning and return graceful default `ProjectProfile` | `tests/unit/scanner-requirements.test.ts` |
| `FAIL-002` | `FEATURE-004` | Not a Git repository (missing `.git` directory) | `git status` command fails with code 128 | Gracefully fall back to scanning all test files (`scope: "all"`) | Set `impactedTestFiles = allTests`, log info notice | `tests/unit/change-impact.test.ts` |
| `FAIL-003` | `FEATURE-006` | Test file destination directory does not exist | Creates intermediate directories recursively | Auto-create target directories (`mkdirSync(dir, { recursive: true })`) | Intermediate directories created without failure | `tests/integration/autonomous-flow.test.ts` |
| `FAIL-004` | `FEATURE-007` | Test failure output contains unparseable binary characters | Sanitizes output stream and attempts regex heuristic matching | Return generic `TEST_BUG` classification rather than crashing | Fall back to default classification | `tests/unit/classifier-diagnostics.test.ts` |
| `FAIL-005` | `FEATURE-008` | Element not found in Visual DOM snapshot | Healing service returns `applied: false` with low confidence | Do not modify test file; recommend manual locator update | Safe no-op on test file; preserve developer source code | `tests/unit/advanced-qa-services.test.ts` |
| `FAIL-006` | `FEATURE-009` | Target server is offline during security testing | Probing requests fail with `ECONNREFUSED` | Mark network-dependent tests as `SKIPPED`; execute static AST checks | Static security rules complete; network error cleanly reported | `tests/unit/security-testing.test.ts` |
| `FAIL-007` | `FEATURE-010` | Postman collection contains undefined dynamic variable `{{missing}}` | Interpolates as literal string or empty string without crashing | Keep `{{missing}}` placeholder intact, log variable warning | Graceful string fallback; continue request chain | `tests/unit/dynamic-variables.test.ts` |
| `FAIL-008` | `FEATURE-014` | Git hook installer run on read-only filesystem | Throws EACCES permission denied error | Catch EACCES error and return `{ installed: false, error: "Permission denied" }` | Graceful error result object returned to caller | `tests/unit/v100-stability-dx-suite.test.ts` |
| `FAIL-009` | `FEATURE-015` | Client sends unknown tool name to MCP server | MCP protocol returns error response `-32601 Method not found` | Standard JSON-RPC error response sent to agent client | Agent handles standard error response cleanly | `tests/unit/interface-parity.test.ts` |
