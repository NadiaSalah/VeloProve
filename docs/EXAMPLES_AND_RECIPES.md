# QAForge Examples & Recipes

Practical, concise recipes for common testing, verification, and autonomous workflows with QAForge.

---

## 🤖 Recipe 1: The Autonomous Coding Agent QA Loop

The standard 10-step verification loop for AI coding agents (Cursor, Windsurf, Claude Code, Cline, Codex):

```bash
# 1. Inspect stack, framework routes, and PRD requirements
npx qaforge inspect

# 2. Identify only files affected by recent git modifications
npx qaforge changed

# 3. Generate risk-prioritized test plan
npx qaforge plan --scope changed

# 4. Materialize test files (preserving developer tests)
npx qaforge generate --overwrite generated-only

# 5. Run tests and collect structured results
npx qaforge test --scope changed

# 6. If failures occur, diagnose root cause
npx qaforge diagnose

# 7. Self-heal locators or inspect code fix recommendations
npx qaforge heal
npx qaforge auto-fix

# 8. Re-run affected tests
npx qaforge test --scope changed

# 9. Verify release readiness
npx qaforge release --ci
```

## 🌐 Recipe 3: Next.js App Router E2E Testing

### Playwright Test Generated by QAForge:
```typescript
import { test, expect } from '@playwright/test';

test.describe('Feature: Checkout Flow', () => {
  test('TC-CHECKOUT-001: Completes checkout with valid cart items', async ({ page }) => {
    await page.goto('/cart');
    await page.getByRole('button', { name: /checkout/i }).click();

    await expect(page).toHaveURL(/\/checkout/);
    await page.getByLabel(/shipping address/i).fill('123 Main St');
    await page.getByRole('button', { name: /place order/i }).click();

    await expect(page.getByRole('heading', { name: /order confirmed/i })).toBeVisible();
  });
});
```

## 🚀 Recipe 4: Express REST API with Dynamic Variables & Auto-Auth

### Native QAForge API Test Spec:
```typescript
import { NativeApiRunner } from '@engnadia/qaforge';

const runner = new NativeApiRunner('http://localhost:3000');

const result = await runner.executeChain([
  {
    id: 'AUTH-LOGIN',
    name: 'Login as Admin',
    method: 'POST',
    path: '/api/auth/login',
    body: { email: 'admin@example.com', password: 'secretpassword' },
    expectedStatus: 200,
    extractVars: { token: 'token', adminId: 'user.id' }
  },
  {
    id: 'CREATE-PRODUCT',
    name: 'Create New Inventory Product',
    method: 'POST',
    path: '/api/products',
    headers: { Authorization: 'Bearer {{token}}' },
    body: { name: 'Widget-{{$uuid}}', price: 29.99 },
    expectedStatus: 201,
    extractVars: { productId: 'id' }
  },
  {
    id: 'DELETE-PRODUCT',
    name: 'Teardown Cleanup Product',
    method: 'DELETE',
    path: '/api/products/{{productId}}',
    headers: { Authorization: 'Bearer {{token}}' },
    expectedStatus: 200
  }
]);
```

## 🚦 Recipe 10: CI/CD Quality Gate (GitHub Actions)

Generate autonomous CI quality gate:
```bash
npx qaforge setup-ci
```

In your CI pipeline:
```yaml
- name: Run QAForge Autonomous Release Gate
  run: npx qaforge release --ci
```
Exits with status code `0` on `READY` / `READY_WITH_WARNINGS` and status code `1` on `NOT_READY` with actionable blocking recommendations.
